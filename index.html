Dimensionamiento de enlace de red Bisección

Una empresa de telecomunicaciones necesita dimensionar la capacidad C, en Mbps, de un enlace de datos que conecta un centro de datos con una sucursal. El tiempo de espera promedio de los paquetes en la cola del enlace, medido en milisegundos, se modela mediante:

T(C) = 1 / (C − 8.5) − 0.35·ln(C − 2)Dominio válido: C > 8.5 (estabilidad del sistema)

En el modelo, C representa la capacidad contratada del enlace y T(C) representa el tiempo promedio de espera. El dominio C>8.5 evita operar en una zona inestable, donde el término 1/(C−8.5) crece sin control.

El equipo de infraestructura determina que la capacidad óptima se obtiene cuando el modelo de espera se hace igual a cero. Por eso se plantea la ecuación de raíz:

f(C) = 1 / (C − 8.5) − 0.35·ln(C − 2) = 0

DominioC > 8.5
ObjetivoCapacidad mínima estable

Aislamiento de la raíz [a, b]

Se evalúa f(C) por signos para localizar un cambio de signo. Cuando C → 8.5⁺, el término 1/(C−8.5) → +∞, de modo que f(C) → +∞. Cuando C crece, ese término se aproxima a 0 mientras −0.35·ln(C−2) decrece sin límite, por lo que f(C) → −∞. Existe entonces una raíz en algún punto intermedio:

Como f(9) > 0 y f(10) < 0, hay cambio de signo ⇒ se garantiza una raíz en [a, b] = [9, 10], dentro del dominio válido C > 8.5.

El método cerrado es apropiado porque el intervalo contiene un cambio de signo y la función está definida en todo el tramo seleccionado.

Equilibrio de migración a la nube Falsa Posición

Una empresa evalúa migrar un sistema de información local, alojado en servidores propios, hacia un proveedor de servicios en la nube. El costo acumulado de mantenerlo localmente, en miles de soles, durante t años es:

C₁(t) = 45 + 12t

El costo acumulado de operarlo en la nube incluye la migración inicial y un costo variable exponencial asociado al crecimiento proyectado de datos y recursos:

C₂(t) = 20·e^(0.4t)

El punto de equilibrio ocurre cuando ambos costos acumulados se igualan; por tanto, se debe encontrar la raíz de:

f(t) = C₁(t) − C₂(t) = 45 + 12t − 20·e^(0.4t) = 0

La lectura de signos permite comparar alternativas: si f(t)>0, el costo local acumulado es mayor que el costo en nube; si f(t)<0, el costo en nube supera al costo local.

El intervalo permite comparar el costo local y el costo en nube antes y después del cruce, que es la interpretación central del problema.

Control de temperatura en centro de datos Punto Fijo

Un centro de datos debe mantener la temperatura de una sala de servidores dentro de un rango adecuado. Debido a la interacción entre la temperatura ambiente, la carga computacional y el sistema de enfriamiento, la temperatura de equilibrio T, en °C, satisface:

T = 18 + 8e−0.15T

Para verificar la raíz, la ecuación se expresa como f(T)=0, donde el equilibrio se alcanza cuando la diferencia entre el valor actual de temperatura y el valor calculado por el modelo es prácticamente nula:

f(T) = T − 18 − 8e−0.15T = 0

Se emplea directamente la forma de iteración T = g(T) y la aproximación inicial indicada en la guía:

g(T) = 18 + 8e−0.15T    |    T0 = 20

La convergencia es razonable porque g′(T) = −1.2e−0.15T y, cerca de la solución, su magnitud es menor que 1.

Dimensionamiento de almacenamiento Newton-Raphson

Una empresa dimensiona un sistema de almacenamiento para una aplicación que procesa grandes volúmenes de información. El tiempo promedio de respuesta t, en milisegundos, se aproxima resolviendo:

f(t) = t³ − 7t − 5 = 0

La solución positiva representa el tiempo de respuesta asociado a una condición de operación. Para Newton-Raphson se usa:

tn+1 = tn − f(tn) / f′(tn)    |    f′(t) = 3t² − 7

La guía no fija un valor inicial para este problema; se propone t₀ = 2 como valor inicial positivo para iniciar la búsqueda de la raíz física. Además, en esa zona f′(t) no es cero, por lo que la iteración puede aplicarse sin división inválida.

Optimización del rendimiento del servidor Secante

Un servidor experimenta una variación en su rendimiento cuando aumenta el número de solicitudes simultáneas. El nivel de carga normalizado x debe satisfacer:

f(x) = e−x − x² + 0.2 = 0

Se busca el valor de x que identifica un punto de operación del servidor. La guía no especifica dos valores iniciales, por lo que se proponen x₀ = 0 y x₁ = 1, valores cercanos a una raíz y con evaluaciones distintas para evitar un denominador nulo en la fórmula de la secante.

Estabilidad de un filtro digital IIR Müller

En procesamiento digital de audio para una plataforma de streaming se utiliza un filtro IIR. Su estabilidad depende de las raíces del polinomio denominador característico D(z): el filtro es estable solo si todas cumplen |z| < 1, es decir, si permanecen dentro del círculo unitario del plano Z.

D(z) = 8z⁴ − 6z³ − 3z² + 3z − 1 = 0Puntos iniciales: z₀=0, z₁=0.5, z₂=1.0 · tolerancia ε=10⁻⁵
PolinomioGrado 4
Criterio|zᵢ| < 1
EntregaRaíces y estabilidad

Delimitación teórica solicitada Descartes · Lagrange · Horner

Criterio de Descartes

D(z) tiene signos +,−,−,+,−: presenta 3 cambios, por lo que posee 3 o 1 raíces reales positivas. D(−z) tiene signos +,+,−,−,−: presenta 1 cambio, así que posee exactamente 1 raíz real negativa.

Cota global de Lagrange

Al normalizar: z⁴−0.75z³−0.375z²+0.375z−0.125. La cota es R=1+max(0.75,0.375,0.375,0.125)=1.75; todas las raíces están en |z|≤1.75.

Esquema de Horner

El polinomio se evalúa como ((((8z−6)z−3)z+3)z−1), reduciendo operaciones y el error de redondeo durante las iteraciones.

Esta delimitación no reemplaza el cálculo numérico: acota y orienta el análisis antes de aplicar Müller, deflación y verificación con módulos.

Müller parte de z₀=0, z₁=0.5 y z₂=1.0 para hallar la primera raíz con ε=10⁻⁵. Después se aplica deflación polinomial, se calculan las raíces restantes, se obtiene cada módulo |zᵢ| y se concluye si el filtro es estable o inestable.

Validación comparativa de métodos Seis métodos

Contrasta un mismo ejercicio con Bisección, Falsa Posición, Punto Fijo, Newton-Raphson, Secante y Müller. Esta vista sirve para revisar convergencia, número de iteraciones, aproximación final y comportamiento del error antes de presentar resultados.

Úsalo como apoyo de validación: permite observar si distintos procedimientos llegan a la misma raíz aproximada, cuántas iteraciones requieren y cómo cambia el error.

g(x), la derivada y el segundo valor son opcionales. Si defines un intervalo con cambio de signo, los métodos abiertos se inicializan dentro de ese tramo para comparar la misma raíz. Müller usa su propia tolerancia absoluta ε; los demás métodos usan error relativo porcentual.

Cómo se usan los valores: Bisección y Falsa Posición usan el intervalo [a,b]. Newton-Raphson y Punto Fijo arrancan desde el punto medio del intervalo objetivo; Secante usa los extremos; Müller usa tres puntos dentro del mismo tramo cuando es posible.
